# Portfolio case study — writing template

Use this structure for each project's deeper case study once it ships
(linked from its `/projects/[slug]` page):

1. Problem
2. Target users
3. Safety constraints
4. Scope (what's in, what's deliberately out)
5. Architecture
6. Data / database design
7. Evidence-grounding or validation approach
8. Testing (including prompt-injection tests where relevant)
9. Screenshots / demo
10. Limitations
11. What I'd do next
12. What I learned
