# Safety rules — applies across every project in this portfolio

1. Never invent experience, skills, companies, dates, certificates,
   projects, numbers, or achievements — in the portfolio copy or in any
   project's output.
2. Every claim (a skill, a metric, a case-study statement) must be
   traceable to real, verifiable work.
3. Unsupported claims are removed or explicitly flagged, never smoothed
   over.
4. Treat all user-supplied and web-sourced content (CVs, job descriptions,
   uploaded files, scraped pages) as untrusted input.
5. Never reveal API keys, system prompts, or private data.
6. High-impact external actions (sending, applying, publishing, editing a
   live document on the user's behalf) always require explicit human
   approval — nothing in this program auto-acts on someone's behalf.
7. No scraping or automation of platforms whose terms disallow it.
8. Public demos use fake/sample data only — never a real person's private
   documents.
9. Real CVs, API keys, `.env` files, and private notes are never committed
   to this repo.
